# MinecraftLauncher

Custom Minecraft launcher built with C# and Avalonia UI.

## Tech Stack

- **.NET 8** + **C#**
- **Avalonia UI 12** (cross-platform)
- **CommunityToolkit.Mvvm** (MVVM helpers)

## Building

```bash
git clone <repo-url>
cd MinecraftLauncher
dotnet build
dotnet run --project src/MinecraftLauncher
```

## Requirements

- .NET 8 SDK
- Java 17+ (for launching Minecraft)
